## 自我介绍

你好，我是 **22/7.** 👋，一名计算机科学与技术本科生，预计 2027 年毕业。

我主要关注 **AI-Native DevOps、SRE 与云原生基础设施**，喜欢把复杂的系统问题拆解成可观测、可自动化、可复用的工程实践。

目前，我正在使用 Go、Kubernetes、CI/CD 与 LLM 构建个人云原生实验平台和智能 Operator，探索自然语言配置、故障诊断与自动化修复。我的目标是为开发团队提供更稳定、更高效、可持续交付的基础设施。

## 🛠️ 工程理念

- **消除重复劳动**：用自动化替代手工操作，让部署、排障和环境管理可重复、可追溯。
- **用观测理解系统**：通过指标、日志和链路把系统状态呈现出来，让排障从猜测变成定位。
- **一切皆可复用**：坚持基础设施即代码，沉淀脚本、配置和文档，减少对个人经验的依赖。
- **AI 作为工程伙伴**：用 AI 加速探索和交付，同时保持人工审查、测试验证与安全边界。

## 🛠️ 技术栈

### 🤖 AI-Native 与模型实践

- 关注大语言模型的发展，使用 **Ollama** 或云端模型进行垂直场景的对比测试，重点观察效果、延迟和成本。
- 使用 **Cursor、Codex、OpenCode** 等 AI 编程工具辅助设计、编码、调试和文档整理，并保持对生成结果的审查。
- 使用 **NVIDIA Container Toolkit** 完成 GPU 容器环境配置，结合 **uv、Miniconda、MLflow** 进行算法环境和模型生命周期管理。

### 🐧 Linux 与系统排障

- 以 **CachyOS Linux** 作为主力开发与运维演练环境，使用 **Niri** 搭建简洁高效的 Wayland 工作区。
- 使用 **strace** 跟踪系统调用，使用 **tcpdump**、**socat** 和 **nmap** 分析网络、端口及套接字问题。
- 使用 **Btrfs + Snapper** 管理系统快照，实践文件级回滚、故障恢复和备份容灾。

### ☸️ 云原生与虚拟化

- 使用 **Kubernetes、OpenLens、client-go** 进行资源观测和控制器开发，掌握 SharedInformer 与 RBAC 的基本实践。
- 使用 **Podman** 实践 Rootless 容器，结合 Docker 多阶段构建制作更小、更安全的镜像。
- 使用 **QEMU / KVM、Libvirt、virt-manager** 管理虚拟机环境，并通过 **Nix** 提升开发环境的一致性和可复现性。

### 🛠️ IaC、CI/CD 与开发工具

- 使用 **Terraform、Helm、GitHub Actions** 编写基础设施和持续交付流程，实践 GitOps、Lint、编译测试与通知告警。
- 使用 **Bruno** 管理 Git 友好的 API 请求和测试用例，让接口调试过程可以进入版本控制。
- 核心语言：**Golang、Python、Shell**。
